Sales Data Using Power BI :
This repository contains interactive dashboards and reports built using Microsoft Power BI as part of my internship project.

🥪 Project 1 — Sandwich Sales Dashboard
Overview :
An interactive Key Performance Indicator (KPI) Dashboard built to analyze and visualize sandwich sales data.

📌 Key Metrics Tracked
Total Revenue — 817.86K ,
Total Orders — 21K ,
Total Sandwiches Sold — 50K ,
Average Order Value — 38.31 ,
Average Sandwiches per Order — 2.32.

🛠️ Tools Used
Microsoft Power BI ,
DAX (Data Analysis Expressions) ,
Excel / CSV (Data Source).

🙋 About
This is my first Power BI dashboard, created during my internship to learn data visualization and DAX aggregation functions like SUM, AVERAGE, COUNT and COUNTROWS.
